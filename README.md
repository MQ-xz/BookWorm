# BookWorm

An AI-based Smart Notebook

BookWorm is a note-taking application integrated with AI, enabling users to take notes with recommendations powered by [OpenAI API](https://openai.com/api)'s [GPT-3](https://arxiv.org/abs/2005.14165) model.

---

## Features

- AI-powered note recommendations
- User-friendly interface
- Integration with OpenAI's GPT-3 model
- Cross-platform compatibility

---

## Pre-requirements

- [Python](https://www.python.org/downloads/)
- pip ([installation doc.](https://pip.pypa.io/en/stable/installation/))
- IDE ([VSCode](https://code.visualstudio.com/) recommended)
- [Git](https://git-scm.com/download/win)

---

## Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/BookWorm.git
   ```
2. Navigate to the project directory:
   ```bash
   cd BookWorm
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Usage

1. Run the application:
   ```bash
   python manage.py runserver
   ```
2. Open your browser and navigate to `http://127.0.0.1:8000/`.
